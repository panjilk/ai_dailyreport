# AI 日报视频

自动获取大模型迭代与评测新闻，抽取中文要点，生成 **1080p 横屏 MP4、中文配音、画内字幕、文字日报和来源链接**。画面采用米白背景、橙色标题、分类卡片与章节导航。

**不含定时任务。** 每次手动运行生成一期，不自动上传或发布。

## 直接使用

**时效硬限制：北京时间当天优先，最早只到昨天零点。** 条数不足不扩窗、不用旧闻补齐。模型更新或新评测的实际日期也必须符合要求；不能以新转载日期替代旧事件日期。导入稿件须提供 `event_date`，旧稿会被拒绝。

双击 **`生成日报.cmd`**。程序获取北京时间今天与昨天的新闻，最多收录 8 条，完成后打开本地视频预览页。首次运行会在项目 `.venv` 中安装依赖，需要 Python 3.10 或更高版本和联网。

每次结果单独保存在 `outputs/日期_时间/`，已有日报不会被覆盖：

| 文件 | 内容 |
| --- | --- |
| `index.html` | 本地播放器、章节跳转、新闻卡片和下载入口 |
| `daily.mp4` | H.264 / AAC，1920×1080，24fps，含画内字幕 |
| `report.md` | 分类日报与完整来源 |
| `script.txt` | 各条资讯口播稿 |
| `subtitles.srt` | 可导入剪辑软件的字幕 |
| `briefing.json` | 本期输入，可编辑并重新制作 |
| `timeline.json` | 实际时间轴与配音引擎记录 |
| `cover.png` | 总览封面 |
| `narration.wav` | 独立旁白音频 |
| `assets/` | 卡片及分段配音素材 |

## 命令行

在项目目录用 PowerShell 执行：

```powershell
# 默认：抓取最新新闻并生成视频
.\run.ps1

# 今天与昨天、最多6条（不会早于昨天零点）
.\run.ps1 -Hours 48 -Limit 6

# 默认语速为 +20%，可进一步调到 +30%
.\run.ps1 -Rate 30

# 重新制作大模型单页版
.\run.ps1 -InputFile data/briefing-2026-09-12-current.json

# 只采集文字，先审阅内容
.\run.ps1 -CollectOnly

# 使用核实事件日期的当期内容
.\run.ps1 -InputFile data/briefing-2026-09-12-current.json

# 已安装依赖时，也可直接调用 Python
.\.venv\Scripts\python.exe -m dailyreport --input data/briefing-2026-09-12-current.json --tts sapi
```

首次交付的编辑版素材收录 **2026年9月8–11日** 六条官方来源资讯，明确显示原文日期，并非六条都发生在9月11日。之后默认运行会重新采集，不会自动重播这份稿件。

## 新闻与摘要

选题聚焦 ChatGPT/GPT、Claude、Gemini、DeepSeek、GLM、Qwen、Kimi 等大模型的版本迭代、能力变化和评测效果。排除与模型能力无关的财经、人事、硬件及一般应用新闻。底部导航采用具体模型名；每条新闻单页讲完，正文与口播一致。编辑稿按“版本变化、效果证据、限制条件”组织，区分厂商自测和独立复测。

- 默认启用实测可访问的 **IT之家 RSS**；自动版属于中文媒体原文的机器抽取摘要，不声称经过人工核验。第一期编辑版另附官方来源和研究记录。
- `config.json` 可以添加 RSS/Atom 来源，字段为 `name`、`url`、`enabled`、`ai_only`。`ai_only: false` 会先过滤 AI 相关条目。
- 自动摘要从中文正文选取完整句子，不需要大模型 API 密钥。标题和原文观点保留来源归属；它不会做深层推理或跨文献事实核验，句子衔接可能不如人工编辑稿自然。
- 排除缺少时区/时间、未来及窗口外的新闻；按 URL 与标题去重，不足指定条数时如实减少。原站时间有误的条目可能被排除。
- 单篇文章读取失败会跳过并记入 `report.md`。包含辟谣、纠正语境或无法保留归属限定的文章会保守跳过，因此可能漏掉部分值得报道的内容。没有合格资讯时明确失败，不用旧闻填充。
- 分类为规则判断，可能需要人工调整。可先 `-CollectOnly`，核实输出的 `briefing.json` 中 `event_date`、来源日期与正文，再用 `-InputFile` 制作视频。
- 自动版目前仅处理中文正文，添加英文源不会自动翻译。网站拦截、RSS变更或正文结构变化可能影响采集。

## 配音

默认联网语速为 `+20%`，可通过 `-Rate` 或 `config.json` 的 `speech_rate` 调整。完整标题和所有摘要要点共用同一份画面、口播及字幕文本，不以省略号截断。每条新闻在一页内展示全部标题与要点，读完才切换；内容过长时须重新总结，不会拆页或截断；联网配音校验词级标记与音频尾部。修正版因补全了新闻内容，总时长比旧版略长。

默认 `auto`：先尝试联网的 `zh-CN-XiaoxiaoNeural`，失败后尝试 Windows 已安装的中文语音。联网配音会把公开的口播文字发给语音服务，不需要在本工具中填写密钥；可用性由服务决定。

`-Tts edge` 只使用联网语音；`-Tts sapi` 只使用本地语音。Windows 须已安装中文语音包，本地声音自然度低于联网语音。受限执行环境可能禁止语音引擎或网络访问，可在普通本机 PowerShell 中运行。程序不会把无声文件当作正常成片交付。

如果制作中断，已经采集的 `briefing.json` 会保留。可用 `-InputFile` 指向它重新生成，新结果将写入新目录。

需要中文字体，默认使用 Windows 微软雅黑。其他环境可用 `DAILYREPORT_FONT` 指定中文字体文件；本地语音回退仅适用于 Windows。
